# The World Wide Wayback

An informational website about 1990s web design and how it has changed, built the way a
1997 homepage would have been: HTML 3.2 doctype (quirks mode), `<FONT>` tags, table layouts
with spacer GIFs, `BGCOLOR`/`BACKGROUND` attributes, frames, `<MARQUEE>`, `<BLINK>`, image
maps, hit counter, guestbook, webring, and 88x31 buttons.

## Pages

| File | What it is |
| --- | --- |
| `index.html` | Splash page with the "Frames / No frames" choice |
| `main.html`, `nav.html` | Frameset version (nav on the left) |
| `welcome.html` | Home / What's New |
| `history.html` | Web timeline from 1989 to today (starts in default-gray 1994 style) |
| `anatomy.html` | Field guide to 90s homepage features, with live demos |
| `colors.html` | The 216 web-safe colors as a table |
| `thennow.html` | Side-by-side comparison of 1997 and 2026 |
| `guestbook.html` | Guestbook (saves to the visitor's own browser only) |
| `links.html` | Real 90s sites to visit, plus the sources used for this site |

## Run it locally

```bash
python -m http.server 8097
```

Then open http://localhost:8097/.

## Assets

All GIFs and the MIDI theme song are original and generated by `tools/make_assets.py`
(needs Pillow). Rerun it to regenerate `images/` and `midi/`.

## Where it's not 100% 1997

- `<BLINK>` is gone from every modern browser, so a few lines of CSS bring it back.
- The hit counter and guestbook use `localStorage` in place of a server-side CGI script.
- Browsers no longer play MIDI, so the theme song is played with Web Audio when you click it
  (the real `.mid` file is still available to download).
