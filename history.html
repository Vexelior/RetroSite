The Web Timeline

How we got from one gray page at CERN to... well, whatever this is.

This page is styled on purpose like a 1994 web page: the browser's default gray background, default Times font, default blue links. Before Netscape added <BODY BGCOLOR>, this is what every page looked like. Scroll down and watch the timeline grow from plain gray pages to the stuff on the rest of this site.

Part 1: The Gray Years (1989-1994)

YearWhat happened
1989Tim Berners-Lee, working at CERN, writes the proposal that will become the World Wide Web.
1990-91Berners-Lee builds the first browser (called WorldWideWeb) and the first server. The first website, info.cern.ch, explains what the web is. It is all text, with links.
1993NCSA Mosaic ships and shows images inline with text instead of in a separate window. It uses a gray background and blue links, which became the look of the web. CERN puts the web technology in the public domain.
1994Netscape Navigator 1.0 is released in December, made by many of the Mosaic team. It adds its own tags like <CENTER> and the infamous <BLINK>. The W3C is founded. Hakon Wium Lie proposes Cascading Style Sheets. The first webrings appear, and a little company called Beverly Hills Internet (soon to be GeoCities) starts giving away free home pages.

Part 2: The Homepage Boom (1995-1997)

YearWhat happened
1995Netscape 1.1 brings tables and the BGCOLOR and BACKGROUND attributes. Suddenly pages can be pink or covered in tiled clouds. JavaScript is created at Netscape by Brendan Eich (famously, its first version took about ten days). Microsoft releases Internet Explorer, which answers <BLINK> with <MARQUEE>. HTML 2.0 becomes the first official HTML standard.
1996Netscape 2.0 adds frames and looping animated GIFs. (Fun fact: the block that tells a GIF to loop is still literally named NETSCAPE2.0 inside the file.) David Siegel's book Creating Killer Web Sites popularizes the single-pixel spacer GIF. Lynda Weinman publishes the 216 web-safe colors. CSS level 1 becomes a W3C Recommendation in December. Macromedia buys FutureSplash and renames it Flash. The Space Jam website launches. The Internet Archive starts saving the web.
1997HTML 3.2 becomes a W3C Recommendation, and it officially includes the <FONT> tag and tables. Neither <BLINK> nor <MARQUEE> make the cut. Netscape 4 and Internet Explorer 4 fight the Browser Wars with competing versions of "Dynamic HTML." HTML 4.0 arrives in December and starts telling people to use style sheets instead of <FONT>. (Nobody listens yet.)

Part 3: Peak Web 1.0 (1998-2000)

YearWhat happened
1998Netscape releases its browser code, starting the Mozilla project. CSS2 is published. The Web Standards Project forms to push browser makers to support the standards they helped write. Google is founded in a garage.
1999Yahoo! buys GeoCities, by then one of the most visited sites on the web, for billions. Internet Explorer 5 ships, and IE is winning the Browser Wars. HTML 4.01 becomes the last big HTML standard for nearly 15 years.
2000The dot-com bubble bursts. Flash intro pages with "Skip Intro" buttons are everywhere. The 90s homepage era starts to fade.

Part 4: What Came After

Here's the short version of how we got from <FONT> tags to the modern web. For a side-by-side comparison, see Then vs. Now.

2003
Jeffrey Zeldman's book Designing With Web Standards and the CSS Zen Garden show that table layouts and spacer GIFs can be replaced entirely by CSS.
2004-2005
Firefox 1.0 breaks IE's grip. Gmail and Google Maps show what JavaScript can really do, and the term "Ajax" is coined. "Web 2.0" means rounded corners, gradients, and big friendly buttons.
2007-2008
The iPhone puts the full web in your pocket, without Flash. Google Chrome launches.
October 26, 2009
Yahoo! shuts down GeoCities in the US. Volunteers from the Internet Archive and the Archive Team race to save as much of it as they can.
2010
Ethan Marcotte coins "Responsive Web Design": one layout that adapts to any screen. Steve Jobs publishes "Thoughts on Flash."
2013
Firefox, the last major browser still supporting it, drops <BLINK>. (This site fakes it with a tiny bit of CSS.)
2014
HTML5 becomes a W3C Recommendation.
2017
CSS Grid ships in all major browsers. Twenty years after HTML 3.2, there's finally a real way to build grid layouts without tables.
2020
Adobe ends support for Flash Player on December 31.
2022
Microsoft retires Internet Explorer.
